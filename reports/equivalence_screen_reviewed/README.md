# Exploratory equivalence screen — 2026-11-08

Asks a question the earlier work could not answer: for each narrative term, can
the data **rule out** an association larger than a stated practical size?
Failing to reject zero (the August urgency result) is not the same as showing an
effect is small. This screen tests the second question with two one-sided tests
(TOST) on the reviewed October country-clustered coefficients.

Generated by `python3 -m src.equivalence --output-dir reports/equivalence_screen_reviewed`
(standard library only; reads `reports/expanded_feature_sensitivity_reviewed/*/narrative_coefficients.csv`).
No model was refitted. Tests: `tests/test_equivalence.py`.

## Design

| Item | Choice |
| --- | --- |
| Inputs | Reviewed October OLS (log(1 + days)) and LPM (24-hour) fits, expanded and programme-adjusted, 1,453,840 records, 48 country clusters |
| Reference | t with 47 df on the clustered standard error, matching the saved intervals |
| Edit unit | +1 mention per 100 words for the eight rate terms; +0.5 VADER compound for sentiment |
| Primary bound | ±0.05 log(1 + days), about ±5% of (1 + days); ±1 percentage point for 24-hour completion |
| Sensitivity bounds | ±0.02 and ±0.10 log points; ±0.5 and ±2 percentage points (unadjusted flags) |
| Decision | Equivalent when the BH-adjusted TOST p < 0.05 within each specification × outcome family of nine terms |

**The bounds were set on 2026-11-08, after the estimates were known.** This is an
exploratory screen. A confirmatory test needs a bound agreed before seeing the data,
ideally from a partner's view of a meaningful delay.

## How to read it

1. **Most framing associations are small, not merely non-significant.** Family,
   basic needs, business, agency and third-person framing are bounded within about
   ±5% of funding time and ±1 percentage point of same-day completion per extra
   mention per 100 words, in both specifications.
2. **Urgency and first-person framing are unresolved, not absent.** Their country-
   clustered 90% intervals still reach roughly 6–14% of (1 + days) per
   mention. The August "urgency loses significance" result means the data are
   too noisy for these two terms, not that they do nothing.
3. **Small and nonzero can coexist.** Third-person framing is both bounded and
   different from zero in the expanded duration fit.

## Limits

Observational associations under one specification; programme text is an
unvalidated proxy; completed-funding records only; post-hoc bounds; the edit unit
is only compared with feature variation below, not tied to a tested rewrite.
None of this measures what happens when a description is edited.

Note: "SD ÷ edit unit" is the multiplier from the edit unit to one SD. A value below 1
means one SD is smaller than the edit unit. "±0.05 at 1 SD" is the bound carried to the
SD scale: what a 1 SD change would be associated with at exactly the bound.

**What changes when the coefficients are read per 1 SD** (`per_sd` in the JSON; unadjusted
90% intervals held against the same ±0.05 and ±1 pp, no BH step):

1. **Urgency and first-person framing look small per SD, but only because they are rare.**
   Urgency is absent from 98.7% of
   records and first person from 99.0%.
   Their expanded duration intervals become [-0.0128, 0.0030] and
   [-0.0272, -0.0003] log points per SD, inside the bound.
   That does not resolve them. Their SD reflects the many zeros, not a feasible edit: the median
   description has 92 words, so adding one urgency word is
   about +1 per 100 words, roughly 10 SD. The per-mention result stays unresolved. So few
   descriptions use these words that the data carry little information about them, which
   is consistent with the wide clustered intervals.
2. **Common terms move the other way.** A 1 SD change is larger than one mention for
   family, basic needs, business and third person. Intervals outside the bound per SD:
   Basic needs (expanded, duration); Business (expanded, duration); Basic needs (expanded, 24-hour); Business (expanded, 24-hour); Gratitude (expanded, 24-hour); Family (programme-adjusted, 24-hour); Basic needs (programme-adjusted, 24-hour).
3. **Third-person framing is the largest common association** at about
   -0.029 log points per SD (expanded), still inside the bound.

SD is a scale for comparison, not an estimate of what a rewrite would change. Edit size
remains an open design input for any pilot.
