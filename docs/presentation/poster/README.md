## Original version

Generated using the built-in image-generation tool. The yellow, black and
white palette references UNSW's visual identity; the original illustration
uses the competition's global crowdfunding theme. The UNSW name is rendered
as text, not an official logo. This is a team project showcase, not an official
university publication or an award certificate.

Recognition, team affiliation, eight finalists, 44 registered teams and the
September 2026 date were checked against the [official UNSW competition
page](https://www.unsw.edu.au/business/our-schools/marketing/news-events/student-events/MA-hackathon)
on 2026-10-24. The official page's [hero artwork](https://www.unsw.edu.au/content/dam/images/business/marketing/events/2026-04-ma-hackathon-images/2026-04-hero-image.png)
was inspected for thematic reference; it is not reproduced in the poster.

Research copy follows the [project case study](../../3_portfolio_case_study.md).
The rounded 1.45M denotes the full input of 1,453,846 loan records from
2016–2025, not every model's eligible sample. The poster presents research
scope and methods, not causal findings or later sensitivity results as part
of the submitted achievement. The map and connections are conceptual art.

Visually checked the final render for text accuracy, legibility, spacing and
correct finalist wording. No analysis code or submitted artifacts changed.
