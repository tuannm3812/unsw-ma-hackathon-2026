# Pinned direct numerical/statistical environment - NOT a complete lock
# and NOT a bit-for-bit artifact reproduction guarantee. It pins exactly
# requirements.txt's own direct packages (scipy is now itself a direct
# dependency - src/statistical_analysis.py imports it for the few-cluster
# t reference - and remains the package most likely to shift
# statsmodels/scikit-learn numerical edge-case/warning behavior) - it does not pin the rest of the
# transitive dependency tree, and it does not cover the separate
# artifact-rendering toolchain (jupytext/nbconvert for the notebook,
# pandoc/weasyprint plus system fonts for the PDF - see "Optional tooling
# for regenerating docs" in README.md, which is intentionally not in
# requirements.txt at all). A from-scratch environment built only from
# this file can still legitimately differ in exact rendered bytes from
# the committed notebook/PDF for reasons outside this file's scope.
#
# What this file *is* useful for: requirements.txt intentionally uses
# lower bounds (>=) so a normal `pip install -r requirements.txt` stays
# installable as new package versions ship; a different set of versions
# satisfying those same lower bounds can produce different numerical
# edge cases and warnings on identical code (this project hit exactly
# that category of bug more than once during development - see the
# collaboration log's warning-cleanup and reproducibility rounds). This
# file pins down that specific, previously-real risk for the core
# numerical/statistical packages - nothing more.
#
#   pip install -r requirements-lock.txt
#
# Python: 3.9.6 (this repo has no minimum-version check beyond what
# individual packages themselves enforce; Python 3.9+ per README).
#
# Regenerate after intentionally upgrading a dependency (exact-name match
# against requirements.txt, not a substring grep - avoids false positives
# like "notebook_shim" matching "notebook"):
#
#   python3 -c "
#   import subprocess
#   names = {l.split('>=')[0].strip().lower() for l in open('requirements.txt') if l.strip()}
#   for line in subprocess.run(['pip', 'freeze'], capture_output=True, text=True).stdout.splitlines():
#       if '==' in line and line.split('==')[0].lower() in names:
#           print(line)
#   "
#
# then re-verify every committed artifact (tests, real-data CLI run,
# notebook re-execution, PDF re-render) before committing the new lock.
